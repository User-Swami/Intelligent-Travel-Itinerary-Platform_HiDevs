# 🌍 Intelligent Travel Itinerary Platform

> A personalized travel planning assistant powered by AI to generate beautiful day-wise itineraries based on your preferences.

---

## ✨ Overview

This platform generates customized, interactive travel itineraries for users based on selected preferences like destination, duration, and interests. It delivers Google-quality travel recommendations and day-by-day plans using cutting-edge LLMs from Groq.

---

## 💡 Features

- 🧳 Personalized itinerary generation based on user interests and destination
- 🌐 Google-like search experience using LLMs
- 🌈 Colorful, interactive Streamlit UI
- ⚙️ Real-time generation with API integration (Groq)
- 🧠 Recommendation system using natural language prompts
- 📅 Logical, structured, day-wise travel plans

---

## 🧪 Tech Stack

- 🐍 Python
- 🎈 [Streamlit](https://streamlit.io) – Web UI
- 🧠 [LangChain](https://www.langchain.com/)
- ⚡ [Groq](https://console.groq.com) – Fast LLM backend (Gemma or Mixtral)
- 🌐 ChromaDB (optional – not used in single-file version)

---
